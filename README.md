# Prediction-of-early-onset-Type-2-Diabetes-

Using health surveys and national health datasets to make a model that can predict early onset type 2 diabetes.



Description:

&nbsp;	In this project I will focus on predicting the onset and complications of type 2 diabetes using population-level health survey data, primarily from the NHANES package. This project will use statistical and machine learning methods such as logistic regression, LASSO, and likelihood-based models. While using relevant R packages, dataset and key research questions to populate my models in order to complete my desired outcomes.
